# Implement Auth Infrastructure (RFC §8)

## Tasks
- Magic link flow: request → email with signed token → verify → issue JWT + refresh cookie
- Google OAuth 2.0: PKCE flow, exchange code for tokens, create/link user
- Ed25519 JWT access tokens (15 min) + rotating refresh tokens (reuse detection)
- HttpOnly secure cookies via Caddy; CSRF protection via SameSite=Lax
- Endpoints: POST /auth/magic-link, GET /auth/magic-link/verify, POST /auth/google, POST /auth/refresh, POST /auth/logout

## Acceptance
- [ ] Magic link email sends via Resend with correct template
- [ ] Token verification issues valid JWT + refresh cookie
- [ ] Google OAuth redirects to dashboard on success
- [ ] Refresh endpoint rotates tokens, detects reuse
- [ ] Logout clears cookies, invalidates refresh token

## Narrative
- 2026-08-24: Created from RFC v3.1 §8. Go-native auth replaces Supabase Auth.
