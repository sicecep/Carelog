# Auth Middleware & Workspace Scoping (RFC §9, §5)

## Tasks
- JWT verification middleware → user in request context
- Workspace membership resolution middleware → workspace context
- Every sqlc query receives workspace_id from context (primary isolation)
- Postgres RLS as defense-in-depth: set session vars `app.current_workspace_id`, `app.current_user_id`
- Rate limiting middleware (Redis token bucket) on auth endpoints

## Acceptance
- [ ] Request without valid JWT → 401 with JSON envelope
- [ ] Request with valid JWT but no workspace membership → 403
- [ ] sqlc queries automatically scoped to workspace_id
- [ ] RLS blocks cross-tenant queries even if middleware bug ships
- [ ] Auth endpoints rate limited; normal endpoints have generous limits
